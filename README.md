# خطة الإنجليزي التفاعلية — Python + Streamlit

1. فك ضغط الملف.
2. ارفع `app.py` و`requirements.txt` إلى مستودع GitHub.
3. افتح https://share.streamlit.io وسجّل الدخول.
4. اختر Create app، وحدد المستودع والملف الرئيسي `app.py`، ثم Deploy.
5. افتح رابط التطبيق من متصفح الموبايل.

تشغيل محلي:
```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

المحاضرات القديمة الـ17 موجودة مسبقًا، وكل واحدة تبدأ بثلاثة أجزاء قابلة للتغيير إلى 4 أو 5. ويمكن إضافة المحاضرات الجديدة. لكل جزء علامة إنجاز مستقلة. الحفظ في JSON مناسب محليًا، لكن الاستضافة المجانية قد لا تضمن بقاء الملف بعد إعادة التشغيل.
